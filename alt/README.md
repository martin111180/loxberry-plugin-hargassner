# Frühere Skripte (Gemini)

Nur zur Referenz – vollständig durch das Plugin ersetzt (siehe `docs/pruefung-gemini.md`).

* `hargassner_mqtt.py`: alter MQTT-Dienst (Passwort entfernt)
* `hargassner_monitor.py`, `hargassner_id_finder.py`: Terminal-Ansichten, ersetzt durch die Seite „Werte“ im Plugin
* `hargassner_mapping.json`: die bisher ermittelten Feldnamen. In der Weboberfläche unter **Sicherung → Sicherung
  einspielen** importierbar (nur „Feldnamen übernehmen“ anhaken).
